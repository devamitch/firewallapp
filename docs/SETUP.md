# Setup Guide — AI Shield

## Prerequisites

- **Node.js** ≥ 22.11.0
- **Java** JDK 17+
- **Android Studio** with:
  - Android SDK 36
  - NDK 27.1.12297006
  - CMake 3.22.1+
- **React Native CLI** (not Expo)

## Quick Start

### 1. Clone & Install

```bash
cd /Volumes/Amit/my-projects/ai-practice/firewallapp
npm install
```

### 2. Android SDK Setup

```bash
# Install required SDK components
sdkmanager "ndk;27.1.12297006" "cmake;3.22.1"
sdkmanager "build-tools;36.0.0" "platforms;android-36"
```

### 3. Build & Run

```bash
# Start Metro bundler
npx react-native start

# In another terminal, build and run on device/emulator
npx react-native run-android
```

### 4. Download LLM Model (Optional — for deep analysis)

Option A: Download via the app's AI Status screen (tap "Download & Activate LLM Model")

Option B: Manual via ADB
```bash
# Download the GGUF model (~1.5 GB)
wget https://huggingface.co/lmstudio-community/gemma-2-2b-it-GGUF/resolve/main/gemma-2-2b-it-Q4_K_M.gguf -O model.gguf

# Push to device
adb push model.gguf /data/local/tmp/model.gguf
```

## Android Permissions

After installing, the user must:

1. **Notification Listener**: Go to Settings → Apps → Special Access → Notification Access → Enable "AI Shield"
2. **Call Screening**: Go to Settings → Apps → Default Apps → Caller ID & Spam → Select "AI Shield"
3. **Phone Permissions**: Grant phone/call permissions when prompted

These are system-level permissions that cannot be auto-granted.

## Troubleshooting

### "DefaultComponentsRegistry.h not found" in IDE
This is an **IDE-only error**, not a build error. These headers are generated by React Native Codegen at build time. Run a full build first, then the errors will disappear.

### "Hexagon SDK not found — building CPU-only"
This is informational only. The Hexagon SDK is Qualcomm's proprietary NPU SDK. CPU-only builds work perfectly on all Android devices.

### Build fails with "NDK not found"
```bash
sdkmanager "ndk;27.1.12297006"
```
Then set in `android/local.properties`:
```
ndk.dir=/Users/YOUR_USER/Library/Android/sdk/ndk/27.1.12297006
```

### macOS TCC permissions on external drives
If building from an external drive (like `/Volumes/Amit`), grant Terminal "Full Disk Access" in System Settings → Privacy & Security.
